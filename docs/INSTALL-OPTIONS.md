# UltraDeck v8.2.0 install options

## Chromium-family extension
Extract `releases/v8.2.0/UltraDeck-Extension-v8.2.0-chromium-mv3.zip`, then load the extracted folder as an unpacked extension.

## Firefox
Extract `releases/v8.2.0/UltraDeck-Extension-v8.2.0-firefox-mv3.zip` and load it through Firefox extension tooling.

## Standalone userscripts
- `releases/v8.2.0/Tumblr-UltraWide-Deck-v8.2.0.user.js`
- `releases/v8.2.0/Patreon-UltraWide-Deck-v8.2.0.user.js`
- `releases/v8.2.0/X-UltraWide-Deck-v8.2.0.user.js`

All delivery paths are generated from the same runtime and site adapters.
